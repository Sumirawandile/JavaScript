# Sumira Wandile – Portfolio

## How to run
1. Open the `portfolio` folder in VS Code.
2. Right-click `index.html` → **Open with Live Server**.
   (ES6 modules and `fetch()` do not work if you just double-click the file.)

## Files
| File | What it does |
|---|---|
| `index.html` | Page structure, inline + internal JS (P1) |
| `style.css` | Design, light/dark theme, responsive layout |
| `js/main.js` | Entry point, imports all modules, console methods (P1, P11) |
| `js/data.js` | All personal content (P2, P5) |
| `js/theme.js` | Theme toggle saved in localStorage (P9) |
| `js/ui.js` | Typing effect, counters, clock, countdown, visits (P9, P11) |
| `js/sections.js` | About, timeline, skills filter, achievements (P2, P5, P7) |
| `js/projects.js` | Projects loaded with fetch() (P10) |
| `js/contact.js` | Regex form validation + draft saving (P6, P8, P9) |
| `data/projects.json` | Project data |

## To edit
- Your details: `js/data.js`
- Projects: `data/projects.json`
- LinkedIn link: search "Add your LinkedIn link" in `index.html`
- Photo: save it as `assets/profile.jpg` (square photo works best)
- Certificates: put PDFs in `assets/certificates/` with the names listed in the README.txt there
