3. How It Works

fetch()$.getJSON()
TypeBuilt into the browserjQuery library function
ReturnsA PromiseA jqXHR (promise-like) object
JSON parsingManual: response.json()Automatic
HTTP errors (404)Not rejected, check response.okCalls .fail()
 
// fetch()
fetch("data.json")
  .then(res => { if (!res.ok) throw new Error(res.status); return res.json(); })
  .then(data => renderTable(data.languages))
  .catch(err => showError(err));

// jQuery
$.getJSON("data.json")
  .done(data => renderTable(data.languages))
  .fail((xhr, status, err) => showError(err));
